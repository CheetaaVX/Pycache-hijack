# pycache-hijack

**Python `.pyc` bytecode cache hijacking tool**

A lightweight Python tool for replacing compiled bytecode inside `.pyc` cache files while preserving the original header. Useful for security research and authorized privilege escalation testing.

[Repository](https://github.com/CheetaaVX/pycache-hijack) · [Source](https://github.com/CheetaaVX/pycache-hijack/blob/main/Pycache.py)

</div>

---

## Overview

pycache-hijack modifies compiled Python cache files inside `__pycache__` directories without modifying the original `.py` source file.

It preserves the original cache header and replaces the bytecode with a custom payload that can execute when the affected module is imported and Python accepts the modified cache.

## Features

- **Bytecode manipulation**
  - Preserves the original 16-byte `.pyc` header.
  - Replaces the existing compiled bytecode.
  - Generates bytecode using Python's `compile()` and `marshal` modules.
- **Command execution**
  - Supports custom shell commands.
  - Handles command arguments and quoting.
  - Uses Python's `os.system()` for execution.
- **Lightweight**
  - No external dependencies.
  - Simple command-line interface.
  - Minimal setup.

## Requirements

- Python 3.7 or newer.
- Write access to the target `.pyc` file.
- Compatible CPython bytecode version.

## Installation

```bash
git clone https://github.com/CheetaaVX/pycache-hijack.git
cd pycache-hijack

chmod +x Pycache.py
```

## Usage

```bash
python3 Pycache.py <target.pyc> <command>
```

### Example

```bash
python3 Pycache.py helper.cpython-310.pyc 'id > /tmp/out'
```

### Additional examples

```bash
# Execute a command
python3 Pycache.py helper.cpython-310.pyc 'whoami'

# Create a test output file
python3 Pycache.py helper.cpython-310.pyc 'id > /tmp/result'
```

## How It Works

1. Reads the original `.pyc` header.
2. Generates new Python bytecode containing the supplied command.
3. Preserves the original header.
4. Replaces the existing bytecode body.
5. The payload can execute when Python imports the modified module and accepts the cache.

## Important Notes

- Designed for CPython `.pyc` files.
- The generated bytecode must be compatible with the target Python interpreter.
- Preserving the header does not guarantee cache acceptance in every configuration.
- The affected module must be imported for execution.
- Back up the original cache before testing.

## Responsible Use

Use pycache-hijack only on systems you own or have explicit permission to assess. This project is intended for educational purposes, authorized penetration testing, and security research.
